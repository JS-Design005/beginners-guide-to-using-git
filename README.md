# Introduction To Git

Thank you for taking the time to see my project! 

## Purpose
This is my first project using Git! I made it to learn how to use git and to make a little presentation of what I have learnt.

## Logo
The Git logo was created using CSS. Ai gave me a foundation for the logo which I built on. The official font for the Git logo is a paid font called, "Halis Rounded". As this project is for learning, I chose a similar Microsoft font called Cambria. 

## Git
Git is a free version control tool used by developers. I created this website to learn how to use git. Sharing what I learn with others is a pleasure but please use this guide with caution, as I am still very green and prone to mistakes.

If you want to use git, I recomend visiting their official web page. They have loads of information to help you get started!
