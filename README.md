# Introduction To Git

## Purpose
Thank you for taking the time to see my first Git project! For me, the purpose of this project was to learn how to initiate a repository, stage & commit and create tags. I also wanted this project to be useful and relevant, so I decided to make the webpage about how to use Git.

## Logo
The Git logo was created using CSS. Ai gave me a foundation for the logo which I built on. The official font for the Git logo is a paid font called, "Halis Rounded". As this project is for learning, I chose a similar Microsoft font called Cambria, and fallback serif typefaces. 

## Git
Git is a free version control tool used by developers. While learning how to use Git, I created this webpage as a fun resource for others to learn too. Sharing what I learn with others is a pleasure, but please use this guide with caution, as I am still very green and prone to mistakes.

If you want to use git, I recomend visiting their official web page. They have loads of information to help you get started!
